# 模块组合与恢复

| 模块 | 可执行选项 | 单独使用时的范围 |
|---|---|---|
| `cutout` | 新建或修正蒙版，可导出透明样本 | 样本分离。去盆、排版、尺、亮度由各自模块决定 |
| `base_cleanup` | 去盆、保留少量真实痕迹或根系、恢复真实基部 | 只改已确认的基部区域，无盆记不适用 |
| `background` | 黑色、指定纯色、透明或保持 | 需要已有分离层或透明度；缺少时说明分离依赖 |
| `transform` | 旋转、可逆裁切、扩画布、等比缩放 | 执行指定几何变换，核对既有尺与样本的对应关系 |
| `center` | 画布或内容区居中、指定基线对齐 | 整体平移像素及链接蒙版，保留尺度和尺。空间不足时说明边距 |
| `scale_bar` | 新增、重校准、重算、保留或移除 | 保持样本形态、位置、蒙版与明暗 |
| `brightness` | 色卡参照、展示匹配、保持或从已知来源恢复 | 保持构图、尺寸、边缘、背景、尺和文字。白平衡、色相统一、自动色阶需另行指定 |
| `export` | PSD、PNG、透明 PNG、JPEG 预览、检查或复制 | 格式转换保留画面；另有要求的缩略图属于派生输出，记录缩放 |

## 依赖与变更

- 按自然语言生成内部计划，用户可随时增删模块。关闭是跳过，保留已有结果。抠图关闭而平面图需要换底时，先找可用分离结果；如需新做分离，核对它是否在用户已授权范围。
- 缩放开启、改尺关闭时，现有尺与样本须共享等比变换并保留物理标签，同时记录最终像素尺度。若尺的位置和线长也须保持，保持原倍率或说明取舍。跨样本物理尺寸比较采用共同 px/mm。
- 明确要求移除或恢复时，优先在 PSD 副本隐藏或停用对应图层。平面黑底图的标记仅在确认全部位于空背景时可恢复为已知背景；遮盖组织时查原图。恢复背景、盆和基部用来源像素层。恢复亮度用原层或来源；烘焙 PNG 的逆 Gamma 无法找回取整、剪切信息。恢复几何优先用未损来源、变换或历史。
- 中途改开关，按检查点回退有依据的操作。只要求后续跳过时沿用已有状态。无法恢复的部分记入待复核，其余继续。
