# 科研展示图亮度

| 用途与依据 | 处理方式 |
|---|---|
| 用途未知 | 先保留亮度，必要时确认用途。 |
| 展示或性状比较，有可靠独立参照 | 用独立灰阶纠正拍摄偏差。性状定量仍须用原始或经验证的校准数据。 |
| 外形展示，已要求匹配且缺少独立参照 | 用已确认的同类参考做展示匹配。 |
| 性状比较无可靠独立参照，或展示未要求亮度匹配 | 保留像素和材料差异。 |

只在亮度模块启用时选方法。`python scripts/brightness_policy.py --purpose phenotype` 可生成决策记录。用途和参照由执行者核实；脚本只根据输入选择分支。

## 选择参照

优先核对本张原片与参考原片中的中性灰阶。同批借用色卡参照需要证据表明曝光、白平衡、光源、受光条件与既有后处理一致。检查色卡反光、阴影、剪切与灰阶顺序，亮块过曝时可保留有效的中暗灰阶，并记录失效原因。

先确认原片与展示图按样本 ID 正确对应。原图与展示图的色彩空间、色调曲线及已有处理会影响参数传递。已有调色先对照校正后的原图再选曲线；RAW 曝光滑块值无法直接用于 8 位 PNG。白色比例尺、纸标签或样本本身缺少独立灰卡证据。指定参考沿用其当前外观，若作为输出交付则原样复制。

## 计算与应用

对 8 位 RGB 展示图，可用编码亮度代理 `Y = 0.2126 R + 0.7152 G + 0.0722 B`，范围 0–255。它未经线性化，参数用于展示色调。

- **展示匹配**。优先从样本蒙版内取统计，排除背景、尺和标签。可用第 70 百分位 `P70`；对有效的 `0 < P,P_ref < 255` 计算 `gamma = ln(P_ref / 255) / ln(P / 255)`。阈值只用于统计，保留暗叶、细穗及半透明边缘。无有效统计区，复核区域或改用人工参考。
- **相对灰阶**。从有效中性块中心取 RGB 中位数并计算 Y。每一块以 `gamma_k = ln(Y_ref,k / 255) / ln(Y_src,k / 255)` 求补偿，汇总前检查各块一致性。对灰阶失序、剪切或互相矛盾的参照先排查，记录采用或拒绝的依据。
- **曲线**。用 `T(x) = 255 × (x / 255)^gamma` 取样，保留 `(0,0)` 与 `(255,255)`。Gamma 小于 1 提亮，大于 1 压暗。按本批样例确定温和幅度并记录限幅。仅调亮度时，PSD 优先使用明度（Luminosity）曲线剪贴到样本，平面图则用蒙版保护实际标记和背景。明度混合与取整会影响最终 P70；检查色相、亮部剪切、暗部纹理以及深浅绿、成熟度、白垩和透明度差异。

批量任务先试偏暗、参考、偏亮样本。记录参照、可用灰阶或统计区、保护区、处理前后 P70、原始及限幅 Gamma、曲线点和限幅原因。用全批联系表查异常，再放大代表图与异常处。保留用户要求的 PNG 或分层 PSD，并按[任务记录与验收](task-and-validation.md)检查源文件、画布、元数据、黑底和标记。单项亮度处理沿用有效抠图与尺度。
