# 展示亮度演示

以匿名的 8 位 RGB 黑底展示图说明算法。数值用于演示，实际处理按本次样本、构图和独立参照选参数。

- 展示亮度匹配可在已确认的样本蒙版内统计 P70。若用阈值作候选统计，示例取 `Y > 8`，并排除已核实的比例尺和文字区域。小于阈值的样本像素仍保留在图中。
- 例如主体 P70 为 100，展示参考为 140，则 `ln(140/255) / ln(100/255) ≈ 0.64`。可试用 `[0.62, 1.60]` 作为演示限幅，再检查亮部剪切与颜色差异。实际限幅取决于这一批图。参考图原样保留。
- 需要独立灰阶时，取已核实、未剪切的中性灰块中心统计。亮块过曝时可比较仍有效的中暗灰块。灰阶排序、不同色块的 Gamma 一致性及原片对应关系都要复核。
- 尺线、文字与背景保持独立。记录曲线、限幅、保护区，检查实际导出 PNG。需要比较叶色、白垩、透明度或强度时，按[亮度规则](brightness-consistency.md)保护性状差异。
