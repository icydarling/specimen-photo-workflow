# 科研样本照片工作流 v2

面向植株、稻穗和精米的 Codex skill。支持从实拍原片成图、继续已有 PSD、单独处理指定模块及只读验收。原片保持只读，去盆和去杂物使用可编辑蒙版。

技能入口见 [SKILL.md](SKILL.md)。用 `$specimen-photo-workflow-v2` 指定本次模块。

植株与稻穗是已公开的抠图案例。精米展示分离、原排列保留、加尺与展示亮度调整。处理前的图片是遮蔽标签后的实拍展示副本。公共示例的标尺仅供对照版式，校准需用当次原片与拍摄依据。
