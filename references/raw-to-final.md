# 原片到成图

1. **准备副本。** 只读打开拍摄原片，确认样本、路径、尺寸、输出位置和文档 ID，创建独立工作 PSD。保留后续需要的标尺与色卡证据，分别按[尺度](scale-and-centering.md)和[亮度](brightness-consistency.md)规则判断其适用性。
2. **分离与精修。** 原生抠图生成初始蒙版。用允许的局部蒙版工具在工作副本精修，核对路径、文档/图层 ID、尺寸和检查点。按[样本边缘](specimen-edges.md)逐图确认保留范围，按启用项隐藏大盆、旁盆、拍摄台、标签、原尺及色卡。漏掉的组织只能从来源像素恢复。保留原分辨率、原几何的分离 PSD 和蒙版。
3. **排版。** 独立背景层，保留样本与蒙版的链接。优先嵌入智能对象做等比变换，保存累计倍率及主体边界。独立绘制尺线和文字。将可关闭的明度曲线剪贴至样本，保护背景和尺；精米是否调亮由用途决定。
4. **核验与交付。** 在分离阶段检查原片保护，成图阶段检查图层、几何、真正的背景、亮度范围和新尺实测。详见[任务记录与验收](task-and-validation.md)。按所选格式另存，需继续编辑时交付分层 PSD。

验证整条链路时，用最初拍摄原片实际完成所要求的模块，呈现原片、原分辨率分离预览和最终成图。记录来源、蒙版精修、校准依据、实际尺线、亮度层及成品检查。没有可靠尺度或仍有杂物的候选按实际状态标注；已有成图的亮度测试和合成夹具可用作单项验证。

## 原像素核对

需要严格确认分离阶段未重绘时，用同一 Photoshop 解码及色彩设置另存只读原片 PNG 作为基准，在调亮和缩放前逐像素比较分离 PNG 的完全不透明区域。记录基准与原片映射。Pillow 与 Photoshop 的 JPEG 解码可能有差异；半透明边缘用原图和浅、深背景视觉复查。

```text
python scripts/verify_source_pixels.py --source ORIGINAL --expected-source-sha256 HASH --decoded-baseline BASELINE.png --isolated ISOLATED.png --report NEW.json
```

脚本核对原文件哈希、尺寸与完全不透明区域 RGB。基准来源由执行记录证明，蒙版语义与边缘完整性由视觉检查确认。
