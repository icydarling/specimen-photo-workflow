# Photoshop 与 ImageJ 操作

按当前工具版本与界面语言核对操作。

- Photoshop 标尺工具沿已确认刻线中心测距离和坐标，使用图像像素值。
- 图层蒙版用黑色隐藏、白色恢复；可用 Select and Mask 局部细化边缘，保留链接蒙版。
- Image Size 中关联宽高并区分 Resample 与仅修改打印 PPI。物理尺度依据见[尺度计算](scale-and-centering.md)。
- ImageJ 可沿已知距离选线，在 Analyze → Set Scale 设置距离与单位。已校准图的读数可能使用物理单位，应同时核对像素端点。跨图使用 Global 需要共同校准依据。
