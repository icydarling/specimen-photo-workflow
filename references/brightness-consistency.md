# 样本展示图的亮度统一

适用于用户要求将植株、稻穗、精米等照片按指定参考统一展示明暗。目标是纠正有依据的拍摄偏差、改善同类照片的明暗协调，同时保留材料差异。默认不执行白平衡、色相统一、锐化、局部组织修改或生成式处理。

## 1. 来源、参考与处理边界

- 按类别和样本编号映射拍摄原图、已有PSD/展示PNG、指定参考与新输出目录。多张原图候选须确认对应关系后，才能使用其色卡传递校正。
- 用户指定某张现有展示图为亮度标准时，以该展示图当前状态为目标，默认原样保留它；不要先把参考图改亮或重新白平衡，再宣称仍采用原标准。
- 只在新输出或工作副本上修改，不覆盖拍摄原图、旧展示图或先前成果。记录来源SHA256、尺寸、PPI、色彩空间/配置文件和输出路径。
- 已有PSD优先将调整层剪贴到样本层；平面PNG需要识别并保护文字、比例尺及其他标记。亮度任务不改变样本几何、抠图边缘、尺寸和位置。

## 2. 选择校正依据

按以下顺序判断，但只有条件满足时才沿用同批次参数：

1. **本张原图有可靠色卡**：与参考的对应原图比较可用中性灰阶，估计相对色调补偿；实际修改对应展示图副本。
2. **同批次有可靠色卡**：确认相机曝光、白平衡、光源、色卡/样本受光条件和后期处理一致，才使用该批次参照。同一天或同一相机型号不足以证明条件一致。
3. **没有可靠色卡依据**：使用用户指定的同类参考图进行展示亮度匹配；记录“展示匹配”，不标记为绝对曝光或色度校准。

色卡应与样本受到相近照明。检查反光、阴影、剪切和灰阶顺序；亮色块过曝时，可改用仍保有层次的中暗灰阶。卡片检测成功不等于灰阶有效。某张有色卡但不可用时，记录原因，再使用有依据的其他参照或展示匹配。

原图与展示图的色彩空间、色调曲线及既有调整会影响参数传递。仅抠图、排版且未调色的图较易对应；已有额外调色的展示图需对照校正后的原图再确定补偿。RAW曝光滑块值不能机械复制到8位PNG。后加白色比例尺、普通纸标签、米粒自身均不能自动当作标准灰卡。

## 3. 样本亮度统计与Gamma曲线

以下为一批8位RGB黑底PNG实际使用的方法，可作为同类任务的起点；其他位深、透明背景、光照或布局需重新选参数。

### 统计区域

使用编码RGB亮度近似量：

`Y = 0.2126 R + 0.7152 G + 0.0722 B`，取值0–255。

此量未进行sRGB线性化，是展示明暗的统计代理，不是物理亮度或反射率。不要混用线性空间曝光运算的含义。

该批统计使用 `Y > 8` 的可见像素并排除比例尺保护区域，以其第70百分位 `P70` 代表主体中间偏亮部分。阈值只用于统计，不删像素、不生成分割蒙版、不据此删除暗叶、细穗或透明米粒。排除黑底可以避免植株大小、穗枝疏密及留白面积影响整图平均值。

该批左下标记区域为 `x < 0.38W 且 y >= floor(0.88H)`。这是经过版面抽查后采用的保护矩形，统计和PS调整都排除它。其他排版须先确定实际标记区域；如果样本进入该矩形，改用精确标记蒙版或独立图层，不能照搬比例屏蔽真实组织。

### 无可靠色卡的展示匹配

令目标图与参考图的主体统计分别为 `P` 与 `P_ref`：

`gamma = ln(P_ref / 255) / ln(P / 255)`

再用 `T(x) = 255 × (x / 255)^gamma` 构造曲线，`gamma < 1` 提亮、`gamma > 1` 压暗。仅在 `0 < P,P_ref < 255` 且统计区域有效时使用公式；无效时先检查区域或改用人工参考。

### 该批色卡的相对灰阶参照

参考原图有部分亮灰阶过曝，因此使用六级中性灰阶中最暗两块（从亮到暗的第5、6块，即零起始索引4、5）。各灰块取中心小区域RGB中位数，再求Y。对每个可用灰块计算：

`gamma_k = ln(Y_ref,k / 255) / ln(Y_src,k / 255)`

采用两块结果的中位数。它拟合的是与参考灰阶接近的编码色调变换，并非恢复相机绝对曝光值；需要再查看样本成品。

该批自动候选筛选还要求：卡片匹配分数大于0.74；最后两块Y均在25至235之间；第4至第5块、第5至第6块的Y下降均大于8；两块算得的Gamma差小于0.22。匹配包含正向和180°倒置色卡。以上是该卡片、模板与照片的经验筛选条件，不能替代视觉核对，也不能当作其他色卡的通用合格线。

### 幅度限制与参考保留

- 本批将Gamma限制在 `[0.62, 1.60]`，防止过强提亮或压暗；限幅后可能仍与参考有亮度差，不声称逐张完全相同。
- 指定参考始终原样复制；非参考若 `abs(gamma - 1) < 0.002`，本批也原样复制并记录原因。
- 匹配目标是同类展示协调，不强制每张主体灰度分布完全相同。特别留意深绿/浅绿叶片、稻穗成熟度、米粒透明度和白垩差异。统一曝光观感也不证明原有色偏已被消除。

## 4. 在Photoshop中实施

实际图片修改由Photoshop完成；数值分析、清单及哈希核验可用辅助代码。使用当前可用工具并确认文档身份，调整固定到正确文档，遵守工具的脚本与恢复约束。

本批创建曲线调整层，使用以下输入点计算并取整输出：

`[0, 8, 16, 32, 48, 64, 80, 96, 128, 160, 192, 224, 255]`

保持 `(0,0)` 与 `(255,255)` 两端点。将调整层设为 **明度（Luminosity）混合模式**，以样本剪贴或保护标记的蒙版控制范围。明度混合用于尽量减少色相改变，仍需检查饱和组织及亮部剪切。PS曲线插值、取整和其混合运算与上述Y统计不完全相同，因此最终P70不保证严格等于公式目标。

先用同类偏暗、参考、偏亮图作样例，再按主skill的批量上限处理、核验、关闭本任务文档。用户只要PNG时，可导出PNG并保存逐张参数和曲线点；不要因此改写源PSD/PNG。需要后续编辑或用户要求时，另存含调整层的PSD。

该批使用PNG无损导出、压缩级别0；压缩级别只影响文件体积和耗时，不是画质或亮度参数。导出副本后关闭工作文档时，不向来源保存修改。断点续做须核对已有文件与本次计划/哈希，不能只看文件存在就认定成功，也不在已调整的成品上重复叠加曲线。

## 5. 核验与记录

自动核验每张实际成品可打开，并检查：

- 文件名与类别清单对应；画布尺寸和PPI保持；源展示文件SHA256与处理前一致。
- 比例尺/文字保护区域像素完全一致；原有纯黑像素仍为纯黑。若新任务本来要改背景，按已授权范围另定该项检查。
- 指定参考的输出与参考来源文件完全一致；复制到其他目录后，成品与目标文件SHA256相同。

记录每张的样本ID、源路径/哈希、参考图、原图对应关系、色卡可用性与拒绝原因、实际方法、保护区域、调整前后主体P70、Gamma原估计及限幅值、曲线控制点、输出路径/哈希和各项检查结果。原始估计、限幅标记及不可用原因在新任务中应显式保存；不要从这批旧日志中虚构缺失字段。

用覆盖全批的联系表查看明暗异常，再放大核对异常与代表图的叶片、穗枝、米粒纹理、亮部和暗部。区分自动检查、联系表浏览、局部放大检查；未做全批逐张人工审片时，不声称已完成该项。亮度任务无需重做本来有效的抠图和物理尺度校准。
