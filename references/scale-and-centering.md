# 尺度与居中规范

仅对本次已启用的尺度、几何或居中模块应用相应要求。只核验或只平移时不附带重算/新增尺；需要扩画布、缩放等额外操作时，遵守主skill的模块选择和依赖规则。

## 尺度

优先同平面布尺、相机正对主要平面，量较长且清晰区间，再量不同位置区间复核。尺在旁盆不能自动证明与植株同平面。立体样本的不同深度仍有投影限制。

已知区间 L 毫米，端点 (x1,y1)、(x2,y2)：`P=sqrt((x2-x1)^2+(y2-y1)^2)`；`q_source=P/L`。记录各段 q 和相对差异。约 1% 差异可作为复测提示，不是物理准确度承诺。明显透视、尺弯曲或单位矛盾须查明，不能用中位数/平均值消除。

无清晰实物尺时，可采用有可追溯尺寸且同平面的参照物或同次固定成像布置的校准，但要记录证据；不能猜米粒/株高。未知尺度先待校准，不妨碍独立蒙版工作。

`s=s1×s2×…`；`q_final=q_source×s`；`bar_px=bar_mm×q_final`。只裁切/平移不改尺度；宽高不等比变换会改形状，不接受单一比例尺补救，应恢复等比变换或返回原图。已绘尺和样本共同缩放则倍率只计一次。

算术示例（不是实际样本校准）：

```text
python scripts/scale_bar.py --interval 0,0,0,1000,100 --interval 100,0,100,1000,100 --scale 0.5 --bar-mm 20 --source-id arithmetic-demo
```

q_final=5 px/mm，20 mm 线长100 px。矩形尺和文字分层，导出后复测白线实际长度，记录取整误差与可读性。未校准不得复制示例数值充当实尺。

## 居中

左上原点，边界用 `[left,top,right,bottom]`，右/下端点不包含。先选内容区域 R（整画布或明确扣除尺保留区后的区域），记录定义，不偷偷换区域宣称居中。

目标中心 `(cx,cy)=((Rl+Rr)/2,(Rt+Rb)/2)`；主体中心 `(bx,by)=((Bl+Br)/2,(Bt+Bb)/2)`；建议平移 `dx=cx-bx,dy=cy-by`。整像素平移可剩 0.5 px 偏差，工作默认1 px几何阈值须记录，不等于视觉质量或尺度误差标准。

从独立蒙版/透明度测样本边界，排除文字、背景和比例尺。导出检查可同时导出同变换的独立样本透明层/蒙版，避免把白尺文字当主体。黑底阈值、最大连通域只能产生候选，不能删掉暗叶、细芒、离散米粒或半透明组织。

主体边界用于视觉平衡，安全边界包含全部真实组织用于防裁切。精米含所有已确认粒。样本像素和蒙版一起移动且保持链接，不只移动蒙版。视觉重心和包围框中心可能不同；视觉偏移须记录理由及偏差。基部对齐不是严格垂直居中。

四边距 `[Bl-Rl,Bt-Rt,Rr-Br,Rb-Bb]`；中心偏差 `[bx-cx,by-cy]`，另报相对区域宽/高的偏差。最终从实际导出图复测，安全边界不得越出画布/目标区域。如严格居中会裁切，先考虑扩画布；完整处理模式可等比缩放并重算尺，仅居中任务不能静默缩放。无法兼得则报告偏差及原因。

```text
python scripts/layout_check.py --canvas 1000 1800 --bbox 100 100 700 1600 --tolerance 1
```

脚本仅检查已测边界。`--safe-bbox` 可提供更大完整边界，`--region` 指定内容区域；不会寻找样本、验证蒙版或移动图像。
