# 模块开关、移除与组合

## 开关语义

开关是本次处理范围。用户可用自然语言给出组合，不必提交配置文件；按既有上下文填写内部计划即可。

```yaml
modules:
  cutout: false
  base_cleanup: false
  background: false
  transform: false
  center: false
  scale_bar: false
  brightness: true
  export: true
output_formats: [PNG]
```

这个例子只执行亮度与PNG导出。`false` 表示不执行，也不反向撤销已有结果；代码示例中的关闭状态不是全新任务的默认选择。用户可随时增删所需模块，其他独立模块继续。

| 模块 | 常用具体选项 | 单独使用的必要输入 |
|---|---|---|
| cutout | 新建蒙版、只修指定边缘、保留、恢复原背景 | 原图或已有可编辑像素/蒙版及目标范围 |
| base_cleanup | 去大盆留少量真实痕迹、全去盆、保留根系、恢复真实基部 | 能辨认目标基部的来源和已确认保留范围 |
| background | 纯黑、指定纯色、透明、保持 | 已有样本分离结果；缺少时需解决分离依赖 |
| transform | 整体旋转、非破坏性裁切、扩画布、等比缩放 | 目标角度/范围/尺寸与既有尺的处理方式 |
| center | 整画布居中、内容区居中、指定基线对齐、保持 | 已确认完整样本边界和目标区域 |
| scale_bar | 新增、重新校准/重算、保留、显式移除 | 新增/重算需可靠尺度；移除需定位现有标记 |
| brightness | 色卡相对参照、指定参考展示匹配、保持、恢复已知来源 | 样本/参考映射及可靠参照或已确认展示目标 |
| export | PSD、PNG、透明PNG、JPEG预览、只检查不导出 | 用户所选格式、目的地和编辑性要求 |

不能将“关闭模块”理解成删除该模块的能力，也不能把用户未启用某项理解成需要移除现有成品中的该项。若用户明确要永久修改skill能力，再修改skill本身。

## 依赖与不联动规则

- **只抠图**：可输出透明样本和蒙版；不自动去盆、居中、调亮、缩放或添加比例尺。真实组织完整性仍须查验。
- **只处理基部**：只改该局部蒙版/来源范围；保留其他叶片、穗部、颜色、位置和有效尺。没有盆时标为不适用。
- **只换背景**：有现成样本层/透明图时独立修改背景；平面图无法分离背景时，说明需要分离结果，使用已授权手段或提出开启抠图的必要选项。不能在抠图关闭时默默重做全图蒙版。
- **只居中**：只整体平移像素和链接蒙版，不重新分割、不缩放、不重新放置有效尺。空间不足时报告具体边距；扩画布也属于几何模块，不自动执行。
- **缩放开启、比例尺修改关闭**：已有尺与样本可整体同比例变换且证据完整时，保持标示物理长度并记录最终像素尺度；不能只缩放样本而留下失效尺。若要求尺的像素位置/线长也完全不动，则保持样本原倍率或取得必要取舍，不能静默补开比例尺模块。物理大小比较遵守共同px/mm。
- **只比例尺**：依据可追溯原图和变换证据新增/修正尺，保留样本形态、位置、蒙版与明暗。缺少单位、刻度或同平面证据时不编造数值。
- **只亮度**：沿用现有构图和抠图，保护背景、尺和文字；不因色卡存在便顺便做白平衡或色相统一。
- **关闭亮度**：保留当前样本亮度，不从别的任务带入自动色阶、色彩匹配或参考曲线。只关闭输出中的亮度调整层，须有用户明确恢复原亮度的要求。
- **仅导出/格式转换**：不启用额外处理，不改变比例、亮度或排版；用户要求网络缩略图等派生尺寸时单独记录缩放，不能当作原尺寸科研成品。
- **全部关闭**：可按要求只检查、列出问题或复制已确认文件；不声称完成未执行的编辑。记录和原图保护仍保持。

## 显式移除、恢复和关闭后的回退

先区分“本次不要做”与“把已做的去掉”。已有PSD优先隐藏/禁用相应独立背景、比例尺、文字或亮度调整层，另存副本；要保留可编辑状态时不直接删除原层。

- 去掉已有比例尺/标签：优先隐藏对应图层。平面黑底图中，只有确认标记全部位于空背景且不覆盖样本时，才可在精确区域恢复该已知背景并记录；覆盖样本时回查原图，不能生成式补造。
- 撤销亮度：禁用已知调整层或回到原始来源。只有烘焙PNG且无来源时，不能声称精确还原；Gamma逆变换也不能恢复已经丢失的8位取整/剪切细节。
- 恢复背景/盆/基部：从原图或保留的像素层恢复，不能根据目标外观猜画内容。
- 撤销缩放、裁切、重新排版：优先从未损坏来源或可靠变换/历史恢复。裁掉或重采样丢失的细节不以再次放大冒充恢复。

用户在处理中更改开关时，保留检查点并据此回退已知操作；只要求后续跳过时不撤销既有结果。无法恢复的具体项单列，不影响其他已经授权且独立的工作。

## 请求示例与应执行范围

| 请求 | 应执行 | 应保持 |
|---|---|---|
| “只调亮度，按同类参考图参考，输出PNG” | 核对对应类别参考、亮度和PNG导出 | 原图、蒙版、基部、背景、位置、尺寸、已有尺 |
| “抠图黑底，不加尺，不调亮度” | 抠图、黑背景、所需导出 | 样本本身明暗与几何；不擅自去盆 |
| “去大盆留一点真实基部，其他不动” | 基部局部蒙版与必要输出 | 其他边缘、位置、尺、亮度 |
| “只居中，禁止缩放” | 整体平移和几何检查 | 样本像素尺度、形态、比例尺及蒙版范围 |
| “原排版保留，只重算比例尺” | 尺度证据核验、比例尺和相关记录 | 样本位置、形态、明暗和边缘 |
| “去掉已有尺，其他全部保留” | 精确定位并移除/隐藏尺及其文字、核对来源 | 样本、其他标记、背景风格与亮度 |
| “全套，但不要调亮度” | 适用的抠图、基部、背景、几何/排版、可靠尺及所需导出 | 原有明暗和色彩 |

例子中的样本编号只在用户当前指定该参考时使用。配置项与自然语言冲突时，以用户明确指令为准，更新本次计划和记录；不要让默认值推翻用户选择。
